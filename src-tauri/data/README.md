# Postal codes

`postal_codes.tsv` (country, postcode, town, state) powers the offline postcode/town
suggestions in the customer form. It is generated by `build_postal_codes.py`.

Source: [GeoNames](https://www.geonames.org/) postal code data for DE, AT and CH,
licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Company/authority postcodes and Swiss PO box variants are removed; Vienna districts are merged into "Wien".

# Colour profile

`sRGB.icc` is the output intent of the PDF/A-3 invoices (ZUGFeRD/Factur-X). It is the sRGB
IEC61966-2.1 profile created by Graeme W. Gill (ArgyllCMS) and released into the public domain,
as shipped with TeX Live's `colorprofiles` package.

# Countries

`countries.tsv` (ISO 3166-1 alpha-2 code, English name, German name) is the list of countries for
customers and the company address and supplies the country names printed on invoices. The names come
from the Unicode CLDR; the list holds the 249 officially assigned ISO 3166-1 codes, without deprecated,
user-assigned or exceptionally reserved codes such as EU or UK.
